Local-only helper for Home Assistant

Deye Token Assistant

This page extracts a Deye Cloud bearer token and station ID from text you paste. Everything stays inside this browser tab: no login, upload, analytics, cookies, or network requests.

1. Capture a request

Open Deye CloudSign in normally, then open your station.
Developer Tools → NetworkReload the station page and select a request containing /station/.
CopyRight-click the request and choose Copy → Copy as cURL.

2. Paste and analyze locally

3. Copy into Deye Optimizers

Treat the token like a password. Do not publish it in screenshots, issues, diagnostics, or chat.

In Home Assistant open Settings → Devices & services → Add integration → Deye Optimizers, then paste these two values.

Privacy and limitations

  • The assistant never asks for your Deye username or password.
  • It performs no network request and stores nothing.
  • Tokens expire; repeat the process if Home Assistant reports 401/403.
  • If no station is detected, paste a station-list JSON response or a request whose URL contains /station/123456/.
